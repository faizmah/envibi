## 2. KONSEP UTAMA APLIKASI

Narayan Virtual Bank adalah sistem pengelolaan tabungan mandiri.

Sistem administrasi dan pencatatan mengikuti alur bank konvensional, tetapi uang fisik tidak disimpan di kantor bank. Setiap member menyimpan uangnya sendiri di rumah menggunakan kotak tabungan fisik yang telah ditautkan ke rekening melalui NFC.

Setiap member memiliki:

- Akun login.
- Profil identitas.
- Nomor rekening.
- Rekening tabungan.
- Kotak tabungan fisik.
- Tag NFC yang terhubung dengan rekening.
- Riwayat setor dan tarik.
- Saldo tabungan digital.
- Laporan keuangan pribadi.
- Riwayat aktivitas dan notifikasi.

Admin memiliki wewenang untuk mengelola member, memproses permintaan rekening, menyiapkan kotak tabungan, menulis NFC, memverifikasi transaksi, serta memantau seluruh aktivitas.

### Prinsip utama

1. Satu member dapat memiliki satu atau beberapa rekening sesuai kebijakan admin.
2. Satu rekening tabungan memiliki hubungan dengan kotak tabungan fisik.
3. Setiap kotak tabungan memiliki identitas NFC unik.
4. Setiap transaksi wajib tercatat dalam database.
5. Member dan admin mendapatkan pembaruan data secara realtime.
6. Tidak boleh ada perubahan saldo langsung dari browser tanpa validasi backend.
7. Semua aktivitas penting wajib memiliki audit log.
8. Sistem harus membedakan saldo pembukuan dan uang fisik yang disimpan member.

**Catatan operasional:** Sistem ini merupakan platform pembukuan tabungan mandiri, bukan sistem yang dapat membuktikan keberadaan uang tunai secara otomatis. Setoran dan penarikan fisik tetap memerlukan pelaporan serta konfirmasi pengguna. Jangan mengklaim uang fisik telah diverifikasi jika belum ada proses verifikasi yang sesuai.

# 5. SISTEM KOTAK TABUNGAN FISIK

Ini merupakan fitur utama aplikasi.

Setiap member yang rekeningnya telah disetujui akan mendapatkan fasilitas kotak tabungan fisik.

Kotak tabungan berada di rumah masing-masing member.

Admin bertugas menyiapkan identitas kotak, menghubungkan rekening, dan mengaktifkan NFC.

## A. Manajemen kotak tabungan oleh admin

Admin dapat:

- Membuat data kotak tabungan.
- Memberikan kode unik kotak.
- Menghubungkan kotak dengan member.
- Menghubungkan kotak dengan rekening.
- Menentukan status kotak.
- Menyiapkan tag NFC.
- Melihat riwayat pengaitan NFC.
- Mengaktifkan atau menonaktifkan kotak.
- Mencatat pengiriman kotak.
- Memasukkan nomor resi pengiriman.
- Mengubah status pengiriman.

Status kotak:

- `PREPARING`
- `NFC_PENDING`
- `READY_TO_SHIP`
- `SHIPPED`
- `RECEIVED`
- `ACTIVE`
- `SUSPENDED`
- `REPLACED`

## B. Pengaitan rekening dengan NFC

Setiap kotak tabungan memiliki tag NFC.

Admin melakukan proses:

1. Membuka menu pengelolaan kotak.
2. Memilih member.
3. Memilih rekening.
4. Membuat identitas kotak tabungan.
5. Menekan tombol tulis NFC.
6. Mendekatkan tag NFC ke perangkat yang mendukung penulisan NFC.
7. Sistem menulis NDEF URL ke tag.
8. Sistem membaca kembali tag untuk memastikan data berhasil ditulis.
9. Sistem memvalidasi token dan identitas kotak.
10. Sistem mengaktifkan hubungan rekening dengan kotak.

### Format NDEF

Gunakan NDEF URL Record yang mengarah ke alamat aplikasi.

Contoh:

`https://domain-aplikasi.com/nfc/BOX_PUBLIC_TOKEN`

`BOX_PUBLIC_TOKEN` merupakan token identifikasi acak yang tidak mengandung nomor rekening, PIN, password, atau data pribadi.

Jangan menulis informasi sensitif ke dalam tag NFC.

NFC hanya menyimpan tautan identitas kotak. Semua validasi kepemilikan rekening dilakukan oleh backend.

### Fitur NFC yang wajib dibuat

- Tombol `Tulis NFC`.
- Tombol `Baca NFC`.
- Tombol `Verifikasi NFC`.
- Indikator perangkat mendukung NFC.
- Status proses penulisan.
- Status berhasil atau gagal.
- Validasi token.
- Deteksi tag yang sudah digunakan.
- Deteksi tag yang tidak terdaftar.
- Riwayat penulisan NFC.
- Riwayat penggantian tag.
- Mekanisme menonaktifkan token lama jika tag diganti.

Gunakan Web NFC API dengan deteksi dukungan browser.

Jika perangkat tidak mendukung Web NFC, tampilkan petunjuk alternatif. Jangan membuat tombol NFC palsu yang hanya mengubah status tanpa benar-benar menulis atau membaca tag.

Web NFC umumnya memerlukan browser dan perangkat Android yang kompatibel serta koneksi HTTPS. Buat lapisan layanan NFC terpisah agar nantinya dapat digunakan kembali pada aplikasi Android.
